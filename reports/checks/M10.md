# M10 — Live soak

**Pass criterion 10 (60 days in a row with every scheduled run logged and no collection gaps) — PENDING, evaluated automatically every day.**

The soak starts when all five runs are live (after M8). Evidence comes from the daily completeness reports
(`reports/completeness/`), the weekly live scorecards (`reports/scorecards/`) and the Actions run history. At the
end, `uv run smax score --mode live,late` gives the final live scorecard, which is compared with the backtest
scorecard for the same runs and leads.

When the count reaches 60, `milestones.py` writes the final live scorecard (`reports/scorecards/live_soak.md`) and
the live-against-backtest table here. It then takes the pre-registered calibration decision (see `reports/decisions.md`).
